# Reliability

The tracker now uses the product/branch/source model documented in [README.md](README.md).

The central rule is unchanged: a generic or unverified price must never become a branch price. A workflow run is not a successful source check. Original historical files remain intact; the v2 migration only imports previously verified branch observations.

Drakes Findon has a direct branch source. Coles and Woolworths candidate adapters remain disabled until connected and independently validated. Henley Square Foodland and the other candidate shops remain unavailable without an evidenced current observation. Read the README for validation, freshness, free-plan controls and recovery steps.
